# V4.1 · 出入场与缓动

导演模式 → 选中镜头 → 选物件 → 加入入场或退场。在右侧每条轨道选择动作、演出阶段和缓动曲线，修改开始、时长与强度。相片、便签、固定件的实体动作保留，透明度统一渐变。

移动类动作默认「画面外」，可选左／右／上／下和 1–4 倍距离。画外位置按镜头、输出画幅及整个物件尺寸解算，带斜角时向摄影机抬升以避开背板；不再固定偏移两格。需要钉下、夹紧等特写时选「物件附近」，只做贴附动作则选「原位动作 / 淡化」。印章默认附近压印，绳索、打字和笔迹保持原位生长／擦除。

「淡化占比」默认 0.65。入场前段由 0 淡到 1；退场后段由 1 淡到 0。设成 1 会贯穿整段动作，设成 0 明确关闭淡化。更慢更轻的演出可使用 1.8–2.5 秒、柔和缓入缓出和 0.8–1 的淡化占比。

曲线图的横轴是时间，纵轴是动作进度。自定义模式下四个滑块控制贝塞尔曲线的两个控制点，边拖边更新；时间点和坐标限制在 0–1，避免不受控的越界与回弹。淡化使用独立的平滑包络，避免强运动曲线让透明度突然变化。

没有动画轨道的物件保持原样。只有退场的物件从完整可见开始。退场后保持隐藏，下一条入场可以重新出现。同一目标的轨道按开始时间排序；重叠时最后开始的轨道生效，作者应避免重叠以保证连续性。搭建模式始终显示原始工程布局；保存、暂停、回拖和逐帧输出使用同一份数据。

## Agent 字段

原有 Action 必填字段不变，新增字段均可省略。旧工程导入不改写作者的开始时间、时长、布局或机位。

| 字段 | 可选值 / 默认值 |
|---|---|
| `phase` | `in` 默认入场，`out` 退场 |
| `ease` | `cinematic` 默认入场电影缓出；`accelerate` 默认退场加速；另有 `smooth/gentle/linear/custom` |
| `bezier` | 自定义 `[x1,y1,x2,y2]`，四项均 0–1；解算时间轴 x，不把参数 t 当时间 |
| `fade` | 淡化时长占比，0–1，默认 0.65 |
| `origin` | `screen` 默认画外；`local` 附近；`stationary` 原位。stamp 缺省 local |
| `direction` | `left/right/top/bottom`；slide 默认 left，其余移动动作默认 top |
| `travel` | 画外距离倍率，1–4，默认 1。低强度也保证画外起终点 |

一张相片从左侧缓入、停留、向右淡出：

```json
[
  { "id":"photo-in", "targetId":"photo", "start":0.3, "duration":2,
    "type":"slide", "strength":0.5, "phase":"in", "ease":"cinematic",
    "origin":"screen", "direction":"left", "fade":0.85 },
  { "id":"photo-out", "targetId":"photo", "start":4.5, "duration":2,
    "type":"slide", "strength":0.5, "phase":"out", "ease":"accelerate",
    "origin":"screen", "direction":"right", "fade":0.85 }
]
```

宿主淡化传给图钉、墨迹及连接绳；两端淡化取较低值，防止绳与消失端点脱离。独立图钉仍可安排专属动作。移动路径防止穿入背板，没有物件间的碰撞求解。半透明颜色使用实际材质 alpha；阴影和景深通过确定性覆盖溶解跟随，不代表物理透射渲染。

验证：`npm test`、`npm run test:motion`、`npm run test:browser`、`npm run test:v4`。新 GPU 脚本输出关键帧、曲线界面、可编辑示例及 JSON 报告至被 Git 忽略的 `test-results/motion`；通过 `XPIN_URL` 可验证离线发行。
