# 手工验收｜20 秒调查沙盘演出

## 从空白沙盘开始
1. 打开空板，切换暗色板材；拖入 3 张相片、1 份文件，替换本地图片、文件标题和正文。移动/旋转/缩放并改图层。
2. 在不同物件上钉 4 枚图钉，依次选起止钉拉出至少 3 条红绳；移动/旋转任一宿主，所有图钉、绳端应仍贴合。
3. 在相片上画圈、文件上划线；都绑定各自宿主并能随其变换。复制物件/撤销时绑定关系仍准确。
4. 创建 4 个镜头卡，在这些卡中配置相片/文件出现、红绳生长、标注手绘、镜头移动和最终拉远全览。
5. 通过播放头任意 seek，例如 15s→2s→15s，各模块、线条和镜头状态应一致，暂停保持不变。
6. 保存工程、刷新页面、重新导入或打开工程，验证图片、文字、位置、图钉关系、标注与故事都能继续编辑。
7. 分别检查 16:9、9:16 输出窗口，导出一张实际可打开的 PNG；后续录制功能上线后验证视频实际解码，且不包含编辑器 UI。

## 演出参考时序
| 时间 | 动作 | 验证 |
|---|---|---|
| 00–03s | 摄影机推近中央，第一张相片甩入并贴附 | 真实纸张与阴影、镜头构图 |
| 03–06s | 镜头向右横移，文件滑入、图钉钉下 | 动作连贯、绑定 |
| 06–09s | 红绳从 A 钉向 B 钉拉出并轻回弹 | 端点跟随、长度与曲线 |
| 09–13s | 镜头靠近证据局部，红圈/划线沿路径绘制 | 局部标注、可读性 |
| 13–17s | 沿绳移动到另一证据，第三张相片出现 | 空间导航、揭示节奏 |
| 17–20s | 镜头拉远呈现整面证据关系网 | 全览、安全边距、层次 |

## 回归与交付
缩放后准确拾取物件和图钉；复杂旋转/缩放/组合及复制时关系不丢；无关状态不受动画切换污染；从任意时间点开始播放结果一致；保存文件不依赖当前 DOM/临时 blob URL；输出文件可解码、无编辑面板、比例正确。

完成后在 PROGRESS.md 中如实填写：代码/文件、构建或交互手测结果、失败项、尚未测试项和下一步。

## 新增：三维材质、追光、实体红绳回归验收

**L0｜三维真实运行：** 在用户目标 Windows Chrome/Edge 实测 GPU 路径、显式渲染模式标识与版本；从 V2 导入/迁移后仍能移动卡片、图钉跟随、红线连接、特写、镜头播放，检查场景坐标和材质数据无丢失。区分 JS 语法通过与 GPU 真运行。

**L1｜投影对比：** 场景至少包含背板、两张高低叠放相纸、文件、金属图钉、两根绳。旋转/移动主灯时，亮面/暗面、接触影与投射影实时变化；相纸投在板上的影子、上层纸投下层纸的影子、图钉与绳子的细影均能看到。别把固定 CSS/drop-shadow 判作通过。

**L2｜手动追光：** 不动摄影机，点选「追光」在 A 证据上落光；拖动光斑到 B，A 变暗、B 变亮，周围物件在光线穿过时有正确阴影；调强度/锥角/软边/色温可实时看见变化。绑定 B 后拖动/旋转 B，光斑跟随正确。录入 4 段 LightCue：点亮 A→扫向 B→缩小光圈突出连线→退出；任意 seek 后位置/亮度/投影一致，工程保存重开后仍正确。

**L3｜立体绳近景：** 镜头从正面移到 60° 斜侧面，绳有圆/绞制截面而非始终屏幕等宽平线，能看到编织纹理、高光、绕过图钉的空间关系及落在纸/板上的阴影。移动任一宿主，绳两端与多连接仍正确；受光改变时反光与阴影相应改变。

**L4｜材质特写：** 同构图切换硬光/柔光，在相纸边、纸纤维、胶带、金属图钉、软木背板特写中，能区分材质与厚度；文字/照片仍清晰，没有明显过曝、光漏、Z-Fighting 或假影穿帮。

**L5｜导演与输出：** 20 秒演出中摄影机从证据 A 运到 B、追光独立平滑转移、绳逐段拉出、标注绘制，最终拉远全景；拖动播放头 15s→2s→15s 严格重复画面与光影。不同画幅的 PNG/视频输出与真实播放同场景、不含编辑辅助线。实际下载并打开文件检查。

**性能边界：** 约 20 个资料物件 + 15 根绳 + 2 盏局部灯 + 4 镜头；报告目标机真实帧率、内存、预览/成片质量差别与不足。软件后备应明确声明其光照/阴影/景深限制，不能默认为达标。
