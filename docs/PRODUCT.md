# 产品规格｜差点调查沙盘 Evidence Board Studio

## 产品定位
游戏式无限画布 + 模块化证据拼贴 + 图钉红绳关系 + 手绘标注 + 镜头导演 + 连续播放。让用户像搭建游戏一样手动摆出调查墙，再安排信息什么时候出现、如何建立联系及镜头看向哪里。面向科技科普、人物/事件关系、商业调查、时间线等叙事。

艺术方向：高级纸张拼贴 / 侦探证据墙 / 真实阴影 / 2.5D 层级 / 暗色影像档案。视觉美术、可读性与 Motion 品质优先，不能停留在通用看板 UI。

## 工作台四区
- 左侧「模块背包」：八类模块的缩略预览、搜索和收藏；拖入画布时有透明预览、放置反馈；可自定义保存组合预设。
- 中央「无限沙盘」：空格拖拽平移，滚轮以光标为中心缩放，拖入/框选/旋转/缩放/复制/锁定/排序/对齐/撤销重做；背景可切换材质与网格。
- 右侧「差点控件」：选中物件的图文、外观、位置、附属图钉、连接、动画；常用控件前置、中文分类折叠、可重置。
- 底部「故事编排」：故事卡/镜头步骤可重排；选中步骤展开相机、入场、连线、标注的二级轨道；可拖动播放头、调整时长和节奏。

三种模式：**搭建**（看见全部、编辑整面板）→ **导演**（指定目标、顺序、出场与运镜）→ **播放**（仅显示目标画幅内容，预览/输出）。模式共用场景数据，切换不丢布局。

同一类型先做一个有成熟质感、真实交互的母版，再扩充变体；模块总数不代替质量。

## 高频操作与交互细节
1. 从背包拖相纸到板上：显示放置投影，松手自动生成纸边和接触阴影，可设置轻微不规则旋转。单击选中、双击替换照片、拖手柄旋转与缩放。
2. 点击图钉工具，再点击相纸/文件指定点：图钉绑定宿主局部坐标，移动/旋转/缩放宿主时一起移动；空白处也可放独立钉。
3. 选择连线工具，依次点图钉 A、B：光标跟随预览，创建自动贴合的绳线；允许一钉多线。调整粗细、弯曲、松弛、控制点、张力与颜色，支持从 A 到 B 的生长和回弹。
4. 手绘红圈/划线：可以绑定照片或文件，也可挂在沙盘坐标；绑定的笔迹随宿主变换，演出时沿路径逐步绘制。
5. 多选保存为复合模块：照片+题注+图钉+装饰整体存成可复用预设，组内仍可更换图片和文字，复制组重新生成全部 ID。
6. 全局支持撤销重做、上下层叠次序、剪贴复制、锁定、隐藏、吸附、框选及素材替换；画布移动不得误拖物件。

## 导演模式
完成布局后选中目标/组合，点击「加入镜头」：自动计算含安全边距的近景/全景构图，保存镜头的视点、缩放、旋转、时长与缓动；可拖动画框覆盖自动建议。镜头从当前状态平滑衔接下一目标。

预制运镜：目标自动对焦、横移探索、沿红绳追踪、快速甩镜、缓慢推近、拉远全览、轻微漂移、倾斜构图。可调终点、持续时间和曲线。

预制入场：相片甩入贴附、文件滑入压落、标签贴入/打字、图钉钉入振动、绳索逐段拉出、圈线手绘、印章压下、组合错峰出现。每项可调开始、时长、延迟与强度。

一级故事卡调整顺序；二级轨道仅在需要时展开细调相机/对象/绳/标注和重叠，降低使用门槛。取景框支持 16:9、9:16、3:4、1:1，编辑无限板不等于输出画面。

## 2.5D 视觉质感
至少区分：背景板 → 物件接触影 → 纸张与图片 → 图钉/胶带/红绳 → 标注 → 摄影机前景。材质包括细纹、卷边/撕边、厚度、细微磨损、适量散射阴影；绳线需有弧度与遮挡、图钉需有高光与钉入感。随机效果可重复，文字不能为了风格而变得难读。可增加轻景深、视差、颗粒、动势但不能损害信息层级。

## 验收体验
空板→相纸/文件→图片文字替换→图钉→红绳→标注→镜头步骤→播放和任意 seek→可编辑工程保存重开→无 UI 的画面导出。主要靠鼠标完成。
