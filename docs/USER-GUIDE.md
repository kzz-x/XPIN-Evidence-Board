# 人类使用与制作指南

适用 Studio V5。先完成一个小故事，再精修材质与运镜。Agent 的代码制作入口见 [AGENT-NATIVE](AGENT-NATIVE.md)。

## 1. 打开软件，保留作品

**直接使用：** 下载 [离线 HTML](../releases/XPIN-Evidence-Board-Studio-V5.1.html)，保存到本机，用支持 WebGL2 的桌面 Edge / Chrome 打开。无需安装 Node。浏览器若把 HTML 显示成源码，先下载原文件再打开。

**源码运行：** 安装 Node.js 22.12+，在仓库执行：

```sh
npm ci
npm run dev
```

打开终端实际给出的本地地址。需要修改源码时用这一入口；生成离线版可运行 `npm run build` 后再运行 `npm run standalone`。

| 文件 / 功能 | 保存的是什么 | 何时使用 |
|---|---|---|
| 工作台 HTML | 软件、内置素材与渲染程序 | 换电脑运行软件 |
| 「保存工程」得到的 JSON | 布局、图文、内嵌图片／音频、字体名称、灯光、镜头、动画 | 备份、继续编辑、交给 Agent |
| 本地自动保存 | 当前浏览器内的恢复副本 | 意外刷新恢复；不能替代工程文件 |
| PNG / MP4 / WebM | 渲染结果 | 分享、剪辑、发布；不能还原编辑工程 |

做大修改、换版本或载入另一个项目前，先「保存工程」。旧 V3/V4 工程可在 V5 打开；V2 可经工作台导入转换，再保存为 version 3。字体文件不随 JSON 内嵌，换电脑需安装相同字体。

## 2. 十分钟做一个故事

1. 选「空白调查板」。在「场景」选软木或毛毡，先用影棚质量；设置画幅和实体边框。
2. 从背包拖入一张相片和一份文件。选中后在「物件」改标题／正文；使用更换图片按钮载入本地 PNG、JPG、WebP 或 SVG。
3. 按 `P`，分别点相片和文件钉上图钉。按 `C`，依次点两枚钉，创建实体绳。拖动纸张检查图钉和绳端跟随。
4. 选文件，在画笔工作台选择笔种、颜色和粗细，加入画圈或划线。也可按 `M` 在纸面自由画。
5. 在「布光」选一个电影预设，例如窗边午后；再调亮度、方向与曝光，让照片和文字都读得清。
6. 选中相片，添加故事镜头；再为文件加一个镜头，最后补全览。逐张选底部故事卡调整时长与机位；按 `0` 监看摄影机。
7. 选物件后在「物件动画」中添加入场，为绳加入生长、标注加入逐笔；让图钉在纸张停稳后钉入，绳在两枚钉出现后拉出。
8. 播放与回拖，检查首帧、中间和结尾。保存工程，先输出一张 PNG 确认，再按需要输出视频。

想先看一个完整的数据例子，可让 Agent 按 [快速入口](START-HERE.md) 编译 `examples/quickstart/scene.json`，再用「打开」载入生成的 `project.json`。示例有 4 件物件、2 枚宿主钉、1 根绳、纸面标注、窗光、3 镜头和 12 秒演出。地图是自制矢量占位素材，制作真实作品时请换成高质量原始图片。

## 3. 统一创作台与自由视角

搭建、导演和播放已合并。中央观察视角与作品摄影机独立：点故事卡只选择镜头，拖播放头或播放故事都保留你的自由视角。

| 区域 | 用法 |
|---|---|
| 左侧模块背包 | 分类、搜索、收藏、拖放、组合预设 |
| 中央沙盘 | 选择、摆放、自由观察；可从旁边查看动画与投影 |
| 右侧控件 | 物件、布光、场景、镜头；重要内容展开，高级项按需展开 |
| 底部故事编排 | 镜头卡、播放头、播放、摄影机选项和完整布置 |

播放键旁勾选「摄影机机位」，或按 `0`，才跟随故事摄影机并显示成片画幅。再按 `0`／取消勾选会恢复原自由视角。在摄影机监看时主动环视、平移或滚轮，会从当前镜头位置接管为自由视角。

「完整布置」显示所有未隐藏物件的源姿态，方便编辑；播放／拖播放头则显示该时间的动画。它不改变视角。要改摄影机，选择镜头后明确点击「用当前机位」。自由观察另存为 `editorView`，保存不会改写故事起始摄影机或镜头。

## 4. 摆放物件和建立关系

当前实体母版包括相纸、拍立得、胶片、文件、新闻剪报、档案文件夹、人物档案、地图、便签、纸标签、日期、图钉、夹子、胶带、回形针和印章。背包中的长期模块愿景不是已实现的变体数量。

- 纸张的 `X/Y` 决定板面位置，`Z` 是离板高度；不要为了“层级”拉得过高，否则接触影会分离。宽高改变形状，缩放改变整体大小。
- 图钉工具创建的钉保存宿主局部坐标；移动、旋转或缩放纸张，钉和绳会跟随。一枚钉可以连接多根绳。
- **背包中的图钉物件与工具钉不同。** 真正作为绳端点，请用图钉工具创建的钉。
- 笔迹绑定画下时选中的宿主。若希望随纸移动，应先选纸再画；没有宿主的笔迹位于沙盘空间。
- 夹子、胶带等背包物件是独立物件，摆在纸上不会自动产生宿主约束。可以同时选择、组合和编辑；不要把“看上去贴住”当成已绑定。
- 多选后可组合、拆组、保存预设、对齐、复制。当前组不是嵌套动画父级；给其中一张纸添加轨道不会自动动画整组固定件。
- 锁定可防误拖，隐藏会在作品中隐藏。纸张重叠可用「关系与组合 → 抬到表面」明确抬高选中物件；实体绳会绕过稳定纸面。复杂柔纸、固定件和绳间交叉仍需检查。

### 纸张、照片与文件夹的质感

选中纸张或照片，在「纸张与磨损」调整磨损程度、撕纸边缘、轻微污渍，或选崭新／轻度存档／陈旧／破旧撕边预设。默认是轻度存档，具有真实不规则薄边和轻微卷曲；磨损为 0 可关闭旧化，原有纸张翘曲仍可独立调整。

「换一组随机细节」改变这一物件的固定种子，可撤销，保存／重开和回拖不会每帧随机。污渍影响颜料，撕边和卷曲影响几何；不是用颜色冒充立体阴影。

文件夹具有厚卡纸封面、带页签封底、五张独立内页和折脊。可以调厚度与封面张开角度；大角度会抬高右侧封面，应检查与绳索、其他纸张的空间关系。宿主图钉会贴合封面高度，原始 local 数值保留。

新增叠放物件会按下方可见纸面留间距。既有布局若纸面相交，仍需用「抬到表面」或手动调整 Z／翘曲；阴影无法代替真实层间空间。投影检查请看纸边与下方接收面，而不是只看物件本身变暗。

## 6. 导演：安排“看哪里”和“何时出现”

### 镜头

先选目标，再添加镜头，工作台会建议构图。右侧可选目标特写、缓慢推近、横移探索、沿绳追踪和全局揭示。沿绳模式需要有效的绳目标。

在自由视角观察满意后，选镜头点「用当前机位」才会写入该镜头；仅拖动观察视角不会自动记录镜头。也可精调目标 XYZ、距离、环视、俯仰、倾斜和焦距。「重新自动构图」会重新计算该镜头；保留手调镜头时不要点它。

镜头按故事卡顺序连续播放。修改顺序或时长会改变后续镜头的全局开始时间。动作中的“开始”是**所属镜头内的秒数**；例如第二镜头从 4 秒开始，轨道开始 0.5 就是故事 4.5 秒。

### 出入场与缓动

选中纸、钉、绳或笔迹，在物件面板「物件动画」选择新增动画所在镜头，再添加入场／退场。镜头面板的「全部物件动画」显示整个故事的同一组轨道；两处修改同步。轨道按所属镜头折叠，可更换所属镜头（保留轨道内相对时间，请复查超时）、预览及移除。纸可柔纸铺贴／滑入／落下，夹子可张开夹紧，钉可钉入，绳可生长，笔迹可逐笔。轨道也可改为退场。

建议从 1.8–2.5 秒的纸张入场开始，选电影缓出或柔和缓入缓出。默认淡化占比 0.65；想更柔和可调到 0.8–1。移动类可以从左、右、上、下画外进入；固定件特写可选「物件附近」，原位展示可选「原位动作 / 淡化」。印章默认在附近压印，绳和笔迹原位生长。

镜头节奏中另有摄影机曲线：丝滑五次缓入缓出、电影抵达、对称贝塞尔、匀速和自定义；「运动占镜头时长」为停留留出时间。自定义控制点有滑块和实时图形。

曲线图横轴是时间，纵轴是动作进度。自定义贝塞尔的四个滑块控制起、终点附近的速度。每个动作的开始、时长、强度、淡化和曲线均可独立调整，详见 [动画控制](MOTION.md)。

没有入场轨道的物件从一开始就可见；有入场的物件在首次入场前隐藏。只有退场则从完整可见开始。物件到下一个镜头会保持当前状态，不会自动重播。不要给同一目标重叠安排多个动作；最后开始的轨道会覆盖前一条，可能产生跳变。

### 一个易读的节奏

先让纸进入并停稳，再钉图钉，再拉绳，最后画圈；给观众留下阅读时间。镜头移动、物件动画和追光可以错开，避免所有东西同时运动。

## 7. 布光、景深、字体

电影布光有暖冷、Noir、柔和档案、侧逆光、追光调查、窗边午后、百叶 Noir、林荫晨光、冷调月窗等预设。窗光是投射到真实三维表面的图案，会受物件遮挡；不只是屏幕上的光斑。

先确定主光方向和环境补光，再调曝光。新增灯后可拖动灯位、落点，或绑定目标。要让灯随时间移动，在镜头中加入「追光 Cue」，设置起止落点／目标、强度、锥角、开始和时长。没有 Cue 的灯仍会持续照明。

景深在场景中设置强度与焦点偏移。强度为 0 或草稿质量时不会显示景深。特写先对准要读的证据，再增加模糊；微小焦点偏移会明显改变绳、钉和纸边的清晰程度。每镜头的「光圈、景深与拉焦」可调 f/0.8–22、自动／手动对焦距离、对焦选中物件，以及拉焦的起始／结束距离、开始和时长。小 f 数产生浅景深；拉焦在景别稳定后开始更易读。场景强度为总开关，草稿档仍关闭模糊。

全局字体在「场景」，单个物件可覆盖字体和字号。「全部跟随此字体」用于统一。浏览器读取本机字体可能不可用，可输入已安装名称，或从源码运行 `scripts/export-fonts.ps1` 导出清单再导入。字体名称保存到工程，字体文件不打包。

## 8. 检查、保存与输出

在场景或镜头面板展开「制作安全检查」运行检查，可定位纸面层间、图钉被埋、绳端时序和摄影机路径问题。报告是稀疏数值检查，不是完整碰撞模拟或画面验收；处理后重新运行。

先把播放头放到开始、中间、每段动作前后及结尾，来回拖几次。检查文字可读、入场起点在画外、纸停稳后固定件贴合、绳端不脱离、阴影和景深自然。静帧不能代替连续运动和口播语义检查。

保存 JSON 后再输出：

| 输出 | 适合用途 | 关键区别 |
|---|---|---|
| 当前帧 PNG | 海报、关键帧、画质检查 | 当前时间与当前自由／摄影机视角，隐藏编辑辅助 |
| 故事 MP4 / WebM | 按时间线完成作品 | 始终按故事摄影机逐帧编码；24/30/60fps；需有镜头 |
| 现场录制 WebM | 记录手动运镜、演示操作 | 可变帧率，帧率设置是更新上限；停止后保存 |

影棚档适合先检查，精制档以 2× 宽高渲染再缩小，更慢且更占内存。长边可选 1920、2560、3840；竖屏会交换横纵尺寸。先验证短段，再决定是否输出长片。4K 长时间输出、低端设备及跨浏览器尚未完整验收。

场景音轨会内嵌 JSON，按故事时间播放，并参与逐帧视频输出。没有口播自动分析和语义对齐功能，需要作者安排镜头节奏。现场录制编码器有启动延迟，刚开始就停止可能没有有效数据；工作台会明确提示，不能把提示当成文件已保存。

## 9. 常见问题

| 现象 | 先检查什么 |
|---|---|
| 时间线里不见物件，完整布置里可见 | 播放头是否早于首次入场、晚于退场，或物件仍在画外 |
| 所有物件开场都已在板上 | 是否仍在完整布置；是否给它们安排了入场轨道 |
| 加了动画没反应 | 目标 ID／选中物是否正确；开始时间是否在镜头内；轨道是否被重叠动作覆盖 |
| 滑入仍从近处开始 | 轨道的起止位置是否为画面外；不要使用旧 V4 HTML |
| 没有景深 | 是否为草稿档、强度是否为 0；用近景检查焦点偏移 |
| 夹子没有跟随纸走 | 独立固定件没有自动宿主绑定，要同步布局并单独安排动作 |
| 字体换电脑后变了 | 目标机器是否安装同名字体；工程不内嵌字库 |
| MP4 编码失败或黑屏 | 更新 Edge／Chrome、检查 WebGL2／编码支持，先试影棚和 WebM |
| 自动保存没恢复 | 是否换了浏览器／地址或清理了站点数据；用手动保存的 JSON 恢复 |

## 10. 让 Agent 帮你制作

交给 Agent：**源码仓库或源码 ZIP + 保存的工程 JSON + 图片／音轨 + 你要保留的内容 + 镜头与节奏描述**。只有一张截图不足以可靠保留原来的可编辑布局。

可复制这段需求：

> 请先读 docs/START-HERE.md、docs/AGENT-NATIVE.md、PROGRESS.md 和我提供的源工程。通过 src/authoring.ts 或 npm run project 原生制作，不操作浏览器界面。保留已有物件 ID、手动布局与未点名的镜头。让照片 A 从左侧柔和进入，镜头缓推；随后图钉钉入、红绳拉向文件 B，窗光追踪 B，在记录上画圈，最后全览。先交付新的可编辑 JSON、修改说明和数据／时序检查结果；我在工作台播放检查后再决定输出视频。

更具体的描述可以补充总时长、画幅、目标字体、哪一秒读哪条信息、不要改动哪些手动内容。数据检查通过不等于电影写实质量或口播同步已达标。
