# Lookdev｜真实材质、灯光追随与三维绳索

## 目标画面
「真实的微缩调查墙 + 电影化灯光叙事」：暗背景不是一片死黑，光圈内纸张纤维、相片边缘、图钉金属和绳索能清楚分辨；阴影有方向与距离感，局部照亮与全景层次都高级、可信。静帧要有空间深度；镜头跟随口播时光束主动揭示下一份证据。

**重要区别**：V2 主要验证三维空间与交互，目前软件后备中的光影与景深带模拟性质。正式 Lookdev 需真实 GPU 受光/投影，不能将倾斜平面、渐变聚光圈、屏幕空间平面线条或纯 CSS 投影当成目标。

## 1. 场景与灯光（L1）
- 建立有真实深度的背板、不同高度的相纸/文件、可遮挡实体固定件与连接绳。所有视觉中的**物理实体**应参与材质受光与投/接影，依贴附/悬空高度与光源方位自然变化；纯 UI 控件不要求投影。
- 一套可调的环境基光 + 一套主造型光 + 可添加的局部聚光灯。支持强方向性斜射、软箱大面积柔光、边缘轮廓光。默认先保证信息可读，主次关系清楚。
- 纸张接触影柔而短，图钉与红绳可产生较细锐的实体投影；光离得越远/光源越大，影形也应出现合理变化。纸叠纸、绳压纸、夹子压纸时能看出层级。
- 高频控件：主光方向/俯仰、亮度、色温、背景亮度、阴影强度与柔软度、曝光、环境补光；高级折叠：阴影分辨率/偏移、AO 细节、色彩管理。
- 预设起点：**Noir 侦探硬光**、**柔和档案桌**、**侧逆光悬浮相片**、**追光调查**、**暖冷混合电影光**。每种预设须展示明显不同的真实材质光照，不只是改色。

## 2. 手动追光 Spotlight & Cue（L2，重点）
### 搭建操作
- 左侧「灯光」像添加图钉一样拖入聚光灯；选中灯后可在三维视图拖动发光位置和**落点/照射圆心**，可从照片、文件或板面选择目标；也可直接点任意位置重新指定落点。
- 编辑态可见简洁光源和锥形辅助线（可隐藏），播放/导出隐藏所有 gizmo。
- 支持**自由追光**（板上手动拖动光斑，镜头不必移动）、**锁定物件**（跟随某张相片移动和旋转）、**随摄影机视线辅助对焦**（可选，但与自由追光独立）。目标关联使用对象 ID + 局部坐标，不能写死一次性屏幕像素。
- 可以多盏灯配合，但面板要容易看清当前选中灯、单独开关与作用对象；主光和追光单独保存，不互相覆盖。

### 必要控件
- 灯位置与朝向、落点、强度、颜色/色温、光束角/光斑大小、软边 Penumbra、照射距离/衰减、阴影开关/柔化、开关与淡入淡出；一键恢复默认。
- 追光的真实亮度变化发生在受光材质上，挡在光前面的物件应该影响光斑或投下阴影，而非单纯叠加圆形半透明遮罩。
- 暗区维持少量可调环境光以保留整体结构；光斑边缘自然，避免廉价舞台彩灯或泛白过曝。

### 导演与时间
- 在某个故事步骤选物件 →「添加追光」产生一条可拖动的灯光 Cue：起始位置、结束位置/目标、开始时刻、持续时间、缓动与 Hold、进入/退出亮度。
- 可排「0–3s 照亮相片 A；3–6s 光斑从 A 扫到文件 B；6–9s 光斑缩窄，红绳被照亮；9–12s 光斑移向下一证据；最后拉远时环境光渐亮」。
- **灯光动画、摄影机、物件、绳索出现、手绘标注使用同一绝对时间源**；拖播放头、打乱镜头顺序或导入工程后，任意时间点结果都应稳定。

## 3. 真正的实体红绳（L3，重点）
- 红绳是有可辨横截面的三维曲线实体，侧面看不是零宽线或永远面向镜头的贴片。表面能看到细微**编织/捻合纤维**，有局部明暗、微弱高光、粗糙度与细小起伏；可选细线、普通棉绳、较粗麻绳、尼龙绳等材质预设。
- 从图钉头部合理位置出发并终止，支持轻微松垂/张力、曲率、厚度、颜色、附加控制点；镜头近距离看得到绳身起伏而不是光滑塑料管。
- 绳能在纸张、板面与其他绳附近形成投影，和其它物件正确遮挡；移动/旋转任一端宿主时，连接关系/绳路径/投影同步更新。连接生长动画遵循空间曲线，能在特写中成立。
- 关键验收：近景沿绳追踪，照明旋转时高光、背光、阴影发生变化；一枚图钉连接多绳也保持独立关系。

## 4. 材质库、光影细节（L4）
- **相片/拍立得**：真实厚度、边缘浅纤维、轻微弯曲、印相层与纸边粗糙度有区别，内容贴图可替换且不会被光打糊。
- **文件/报纸/便签**：真实纸张厚薄、轻折痕、纸纤维和撕边，叠压位置有柔软接触影；文字在斜角运镜仍然可读。
- **图钉/夹子/钉书钉**：塑料与金属分离，高光受环境和主灯影响，能投出尺寸合理的影子。
- **胶带**：半透明、微光泽与边缘贴附，正确遮挡/粘附。
- **沙盘背景**：毛毡、软木、暗色板材与工业板材；真实粗糙度、法线细节和光斑照射的微观层次。
- **标注**：画在纸上/板上的墨迹受宿主表面影响；悬空箭头若为实体模块则遵循光照与深度。

## 5. 镜头与输出（L5）
- 可从正面全景移动到斜侧近景，能绕过前景图钉/绳，产生层间视差；景深对焦点能从绳头过渡到照片主体。
- 带镜头预设：证据自动特写、沿绳追踪、轻掠/横移、冲击甩镜、拉远揭示全局；每个能覆写机位/速度/缓动、焦距/焦点/景深。
- 灯光与镜头可独立表演：摄影机不动时能追光，摄影机移动时灯可以保持指向另一份证据。
- 输出与预览必须基于同一三维场景、灯光 Cue 与渲染链路；1080p 优先，支持质量档位（快速编辑预览 / 高质输出）。不能只导出原二维画布或把编辑 gizmo 输出进成片。

## 6. 质量门槛与性能
- 追求画质优先，同时支持一键降预览负载而不更改保存结果；建议标准压力场景：约 20 张相片/文件 + 15 条绳 + 2 盏局部灯 + 4 镜头演出。看实际帧率、阴影稳定性和交互手感，不把仅能加载算作通过。
- 可以适度使用高质量阴影贴图、接触影增强、PBR 纹理/法线，但**不能用全局固定阴影贴图代替移动灯时必须变化的动态阴影**。多灯投影成本高，应将画质与性能档级开放给用户。
- 无 GPU 环境可保留兼容预览，但应明确标记受限模式，避免以模拟光影宣传物理级效果。
- 参考优先：成熟电影调查墙实拍/广告、真实物体微距光照；可合法使用的纹理、模型资产优先于粗糙程序化占位。
