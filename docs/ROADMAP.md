# 开发路线｜先完成一条可用闭环

每阶段要提交可运行功能、实测记录与下一步，更新 PROGRESS.md。不用逐步讨论无争议技术细节。

## M0 基础工作台
Vite + TypeScript 本地运行；左模块背包、中央无限沙盘、右控件、底部故事带；搭建/导演/播放三模式；世界与屏幕坐标映射；SceneStore 和 ModuleRegistry；至少三个简单模块验证拖拽。

## 最小垂直切片
一张可替换图片的相纸 + 两枚附着图钉 + 一根跟随关系正确的红绳 + 一张自动运镜卡 + 播放头 seek + 完整工程保存与恢复。必须能从空板点出来，不是预置演示。

## M1 可用闭环（最高优先）
至少八种真模块：相纸、文件、便条、图钉、红绳、手绘红圈、背景板和标签/夹子。拖入、选中、移动、旋转、缩放、换图换文字、层级、多选、撤销重做。点击 A、B 图钉建立红线；运动中无断绑；标注绑定。四个故事步骤，支持目标自动构图、推进、平移和拉远；物件入场、线生长和手绘出现；可 seek 播放；保存/重开工程；实际 PNG 输出。按 ACCEPTANCE.md 用真实浏览器验收。

## M2 美术与预制库
八类高频模块扩至约 35–40 种可用变体；优先打磨母版细节：真实纸纹、边缘、褶痕、投影、图钉与红线、局部遮挡。完成组合/拆组、组合保存与复用、材质与环境风格包，资产来源及许可记录。

## M3 导演与输出
高级运镜（沿线追踪/甩镜/漂移/倾斜），二级时间线与轨道错峰、镜头重排、画幅安全线、16:9/9:16/3:4/1:1、音频节奏标记、录制导出、便携项目 ZIP 和多工程恢复测试。

## 开发判断
优先修复真实操作阻碍，再增加视觉与装饰。美术有参考才定方向；不要以 40 个占位标签替代少数成熟模板。所有显示出的控件要有效，实测与未测必须区分。
