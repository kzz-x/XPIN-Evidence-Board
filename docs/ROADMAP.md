# 开发路线｜三维沙盘美术升级

以 [True3D V2](../prototypes/XPIN-Evidence-Board-True3D-V2.html) 为唯一**功能基线**。下一阶段优先升级视觉渲染，同时逐步恢复/加强模块系统；不再从空白 Vite 画板重复开发。

| 顺序 | 阶段 | 交付效果 / 完成条件 |
|---|---|---|
| **L0** | 三维底座合流 | GPU 真三维稳定、可操作板/相片/图钉/连线/镜头；真实标注渲染模式；模块化后只有一个正式产品入口，V2 留原型归档 |
| **L1** | 光照 + 全物件投影 | 主光、环境补光、接触影和阴影质量控制；相片、文件、板、图钉、绳、夹子等物理实体受光并投/接影；改灯位时影子实时变化 |
| **L2** | 手动追光与灯光 Cue | 像移动物件一样拖动光斑；可指向任意世界点/模块并持续跟随；角度/边缘/色温/亮度/距离/投影可调；能安排「照亮 A → 移向 B → 收束 → 熄灭」并保存、Seek |
| **L3** | 真实红绳 | 绳索不再是平面笔划：实体截面与编织感、光照高光、轻微松垂、遮挡与投影；两端固定图钉，任意移动/旋转/增线后关系稳定 |
| **L4** | 整体材质升级 | 相纸/文件厚度、边缘与纹理、微翘曲；图钉金属/塑料，胶带半透明，毛毡/软木板表面。光影、材质、景深在全景和大特写都有质感 |
| **L5** | 电影导演系统 | 摄影机近远景/环绕/沿线跟踪、景深/自动对焦、追光与证据出场统一编排；纯画面导出与实际播放一致，可改镜头顺序、重开工程 |
| **L6** | 模块化与制作闭环 | 扩充 PRODUCT 八类模块和可复用组合，完整拖放/绑定/时间线/参数持久化，多画幅与性能档位；按完整调查演出测试 |

## 顺序与交付原则
**先 L0/L1 建立可信光影，再 L2 追光、L3 绳材质、L4 全场精修。** L5/L6 在质量基线成立后扩展，遇到依赖可在当前阶段补齐。每个里程碑至少提交一个可运行、可编辑、可保存/复现的示例状态（优先沿用 V2 案例），提供真实截图/动态核验、缺陷说明，并更新 PROGRESS.md。

## 质量优先级
Art Direction / 画面质感 > 追光和运镜的叙事感 > 实体/绑定真实性 > 操作流畅性 > 扩充数量。视觉不达标时先改材质/布光/构图，而非靠大量滑块或大规模预设堆功能。

## 完整闭环（保留原开发目标）
空板添加相片/文件 → 换素材/布置 → 钉图钉、拉立体红绳 → 画圈标注 → 布灯并绑定证据 → 给每段口播安排镜头和追光 Cue → 播放 → 时间轴任意 Seek → 保存重开继续编辑 → 输出干净的 16:9 / 9:16 画面。

详细视觉和控件要求见 [LOOKDEV.md](LOOKDEV.md)，分项实测见 [ACCEPTANCE.md](ACCEPTANCE.md)。
