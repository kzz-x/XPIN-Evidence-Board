# XPIN Evidence Board｜差点调查沙盘

**游戏化搭建调查沙盘、用图钉与红线组织关系、用镜头和时间线逐步揭示证据。**

一个中文优先、可本地运行的 HTML 叙事编辑器。用户从空板开始拖入相纸/文件、替换图文、绑定图钉并连线、手绘标注、编排镜头，最后播放、保存可编辑工程与导出画面。

## Codex 直接开始

阅读 [AGENTS.md](AGENTS.md)，按照 [PROGRESS.md](PROGRESS.md) 从首个未完成任务继续开发。先做可操作的完整闭环，再扩展模块和材质。设计详见 [docs/PRODUCT.md](docs/PRODUCT.md)，引擎约束见 [docs/ENGINE.md](docs/ENGINE.md)，验收见 [docs/ACCEPTANCE.md](docs/ACCEPTANCE.md)。

## 本地运行

```bash
npm install
npm run dev
```

建议 Vite + TypeScript + Konva + GSAP。初始仓库提供工程骨架和完整开发说明，不代表交互功能已经完成。
